# CMFB characterization scope

The feedback amplifier compares the sensed output common mode with its reference and adjusts the FDC control voltage.

- Open-loop analysis with an ideal plant checks feedback polarity and return-ratio behavior.
- Closed-loop reference sweeps assess regulation and control-voltage range.
- Reference disturbances exercise recovery toward the nominal common mode.

The fixture uses an ideal plant with gain 500 and a 10-pF error-amplifier output load. Its loop crossover and settling are fixture-dependent, not the integrated FDOTA bandwidth or settling time.

Final stability and common-mode regulation are evaluated with the actual FDC, output sensor, and load in the integrated FDOTA.

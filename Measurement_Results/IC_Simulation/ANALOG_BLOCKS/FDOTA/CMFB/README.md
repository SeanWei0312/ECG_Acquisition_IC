# CMFB design-support files

Nominal-only diagnostics for designing FDOTA; no standalone PVT or MC campaign.

| File or directory | Purpose |
| :--- | :--- |
| `CMFB_Analyze.m` | Terminal summary, workspace diagnostics, and plots |
| `Result_txt/` | Nominal ngspice exports read by MATLAB |
| `Plots/` | Plots generated by the current analyzer |
| `Archive/` | Preserved old summary CSV; not regenerated or read by MATLAB |

Testbenches are directly under `Design_Files/IC Design/Testbench/ANALOG_BLOCKS/FDOTA/CMFB/`:

1. `CMFB_TB_OL.sch` — ideal-plant loop response.
2. `CMFB_TB_CL.sch` — operating point, reference sweep, and transient response.

Run both before `CMFB_Analyze`. The 10-pF fixture load is not the integrated FDOTA output load. Raw-data names match the testbench exports and MATLAB inputs.

Only integrated FDOTA simulation results appear in the project and block reports.

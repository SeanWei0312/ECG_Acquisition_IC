# FDC design-support files

Nominal-only diagnostics for designing FDOTA; no standalone PVT or MC campaign.

| File or directory | Purpose |
| :--- | :--- |
| `FDC_Analyze.m` | Terminal summary, workspace diagnostics, and plots |
| `Result_txt/` | Nominal ngspice exports read by MATLAB |
| `Plots/` | Plots generated by the current analyzer |
| `Archive/` | Preserved old summary CSV and plots no longer generated |

Testbenches are directly under `Design_Files/IC Design/Testbench/ANALOG_BLOCKS/FDOTA/FDC/`:

1. `FDC_TB_OL.sch` — differential operating point, AC, offset, noise, and transient checks.
2. `FDC_TB_VCMFB_SWEEP.sch` — common-mode control-voltage sweep.
3. `FDC_TB_CM_PLANT.sch` — common-mode plant AC response.

Run all three before `FDC_Analyze`. Differential/control-sweep fixtures use 40 pF per output; the plant fixture uses 10 pF. Raw-data names match the testbench exports and MATLAB inputs.

Archive contents are historical, not regenerated or used by the analyzer. Only integrated FDOTA simulation results appear in the project and block reports.
